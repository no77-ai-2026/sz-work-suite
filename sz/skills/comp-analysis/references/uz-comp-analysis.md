# uz-comp-analysis — 우즈베키스탄 컨텍스트

## 적용 맥락
UZ: 급여 실무는 net 표기 관습(세후) — gross/net 환산 명시. IT Park 입주사 면세 혜택 반영.

## 규제·관습 체크
- 통화 표기: UZS 공백 구분(1 000 000 so'm), 환산 시 USD 병기
- 언어: 산출물 언어 옵션 KO/RU/UZ — 공식 제출물은 RU 우선 관습, 소비자 대상은 UZ 병기 권장
- 법령·세무 원문 확인은 lex.uz·soliq.uz — 접근 제약 시 2차 출처 + SECONDARY 표기(조사 심도 규칙 준수)

## 데이터 소스
- 국가 통계: stat.uz / 기업 조회: orginfo.uz(STIR) / 전자정부: my.gov.uz

## 주의
- 비공식 경제·수치 격차를 편향 항목으로 명기
- 노동·세무·전자서명 요건은 개정 잦음 — 산출물에 기준일 명기
