# UZ 듀얼 컨텍스트 — design-system-library

> 한국 gil-design ↔ UZ 듀얼

## 적용 원칙
이 스킬은 **한국 표준 + 우즈베키스탄 듀얼 컨텍스트**로 동작한다. 한국 사용자가 기본이며, UZ(타슈켄트·고려인·한·UZ 합작/ODA) 맥락 요청 시 아래를 반영한다.

## 도메인 컨텍스트
UZ 시장 특화 컨텍스트(트릴링구얼·Telegram·Uzum/Click/Payme·stat.uz/soliq.uz).

## 스킬 특화 노트
디자인 시스템 라이브러리 대비 — 키릴·라틴(우즈벡) 타이포·RTL 미적용 점검.
