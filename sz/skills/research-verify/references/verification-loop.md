# 검증 루프 정본 (verification-loop)

> 출처: 사내 AI 리서치·분석 교육자료(전정우, IQVIA, 2026-08) 재구성.

## 1. 3중 검증 프롬프트 (실물 — 그대로 사용 가능)

```
지금까지 만든 분석 문서를 검증해줘. 세 관점에서 각각 따로 봐줘.

1) 팩트: 모든 수치·고유명사·인용이 출처와 일치하는가
2) 출처: 각 주장을 받치는 출처의 등급(1차 자료 / 산업보고서 / 언론·2차 인용)과
   최신성이 충분한가
3) 논리: MECE 위반, 인과 비약, 숨은 전제, 계산 불일치가 있는가

관점별로 문제 항목을 표로 뽑고, 각 항목에 조치 방안(무엇을 확인해야 하는가)을 붙여줘.
근거 없이 단정된 수치는 반드시 [미검증]으로 분류해줘.
```

적발이 약할 때 폴백: "출처가 '업계 관계자', '들은 이야기'인 문장을 모두 찾아서 별도로 표시해줘."
전형적 적발 대상: 출처 없는 성장률("연 15% 성장(업계 관계자)"), 전문(傳聞) 인용, 자사 발표 수치의 교차검증 누락.

## 2. Red 반론 프롬프트 (실물 — 강화판)

```
너는 이 결론을 반박해야 하는 경쟁 팀 리더다.
이 분석의 결론을 무너뜨릴 수 있는 반론 3개를 근거와 함께 제시하라.

각 반론은 다음을 포함해야 한다.
- 반론의 요지 (한 문장)
- 근거 (분석 내부의 논리적 허점 또는 외부 사실)
- 이 반론이 맞다면 결론이 어떻게 달라지는가

"더 조사가 필요하다" 같은 일반론은 반론으로 인정하지 않는다.
```

수용 후 수정 프롬프트: "반론 N번은 타당하다. 이를 수용해서 결론을 조건부로 다시 써줘. 수정 전 결론과 수정 후 결론을 나란히 보여주고, 무엇이 달라졌는지 한 줄로 설명해줘."

## 3. White 검증 프롬프트 (실물)

```
너는 팩트체커다. 해석 없이, 문서 내 모든 수치·고유명사·인용의 출처와 정확성만
검증하고 미확인 항목에 [미검증]을 표기하라.
```

## 4. 페르소나 — 관점의 분리

원리: 작성자 AI는 자기 결론에 우호적이다(확증편향은 사람만의 문제가 아니다). 역할 분리로 작성자 관점에서 드러나지 않는 결함을 적발한다. 반론의 품질도 규칙으로 설계한다('반드시 근거를 갖춘 반론').

**최소 3역**: 작성자(초안) / Red(반론·리스크) / White(사실·출처).

**확장 5역** (초안을 세 번 거름):

| 역할 | 담당 |
|---|---|
| White | 사실 수집·검증 전담, 해석 금지 |
| Blue | 데이터 드리븐 분석 |
| Red | 반론·리스크·대안 |
| Green | MECE·논리 검증, 재작업 지시 |
| Black | 종합·최종 승인 (승인된 것만 최종본) |

워크플로: White 팩트 수집 → Blue·Red 병렬 초안 → White 재검증 → Green 구조 검증 → Black 승인.
로그 예: Blue "CAGR 15%" 인용 → White "[미검증] 표기 권고" → Green 주석 처리·근거 재구성 지시 → Black 승인, 미검증 수치는 1차 리서치로 이관.

## 5. 하네스 설계 4질문 (검증 루프의 위치)

| # | 질문 | 적용 |
|---|---|---|
| ① 도구 | 무엇을 쓰게 할 것인가 | 웹 리서치·파일 읽기 허용 범위 |
| ② 입력 | 무엇을 알고 시작하게 할 것인가 | 내부 자료 우선 + 출력 규칙 5줄 |
| ③ 순서 | 어떤 단계로 일하게 할 것인가 | 리서치→초안→검증→수정 — **검증 전 최종본 금지** |
| ④ 검증 | 누가 어떻게 재검토하는가 | 3중 검증 + Red 반론 + 사람 승인 |

## 6. 도입 사다리 (사용자 안내용)

1단(오늘, 10분): 출력 규칙 5줄 + 프로젝트 폴더 → 2단(이번 주, 산출물당 +5분): 산출물마다 Red·White 검증 루프 → 3단(이번 달): 반복 업무 스킬화·역할 구조 설계. 2단까지만 가도 품질이 눈에 띄게 달라진다.

## 7. 검증 3원칙

① AI 초안은 '검증 전 문서' — 주니어 초안과 동일 취급 ② 검증은 스킬로 루틴화 — 호출 5초에 동일 품질 QC 재현 ③ 최종 승인은 언제나 사람 — AI는 판단의 재료를 늘릴 뿐. 할루시네이션은 '금지'가 아니라 검증 루프로 '걸러내는' 것.
