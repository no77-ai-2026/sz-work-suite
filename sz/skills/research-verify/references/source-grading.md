# 출처 등급·태그 규칙 (source-grading)

## 1. 출처 등급 3분류

| 등급 | 정의 | 예 | 취급 |
|---|---|---|---|
| **1차 자료** | 원 데이터 생산 주체의 공식 발표 | 정부 통계, 공시·IR, 규제기관 문서, 원 논문 | 표준. 연도·기관·링크 병기 |
| **산업보고서** | 전문기관의 조사·분석 | 시장조사사(IQVIA·Datamonitor 류), 협회 통계, 증권사 산업 리포트 | 허용. 조사 시점·표본 명시 |
| **언론·2차 인용** | 보도·블로그·발표 인용의 인용 | 기사 수치, 컨퍼런스 발언, "업계 관계자" | 단독 사용 금지 — 교차검증 또는 [미검증] |

판정 보조 규칙: 자사 발표 점유율·순위는 이해관계 상충 — 반드시 교차검증. 발행 3년 초과 시장 수치는 최신성 결함으로 플래그. 전문(傳聞)·구두 정보는 즉시 [미검증].

## 2. 태그 체계

| 태그 | 의미 | 규칙 |
|---|---|---|
| **[미검증]** | 출처를 확인할 수 없거나 근거 불충분 | 본문 문장 끝에 표기 + 문서 말미 미검증 표(항목·필요 확인·확인 방법)에 집계 |
| **[추정]** | 내부 자료 기반이지만 추론이 섞임 | 추정 근거를 괄호로 병기 |
| **(검증완료)** | 1차 자료로 확인됨 | 출처 병기로 갈음 가능 |
| **(부분검증)** | 일부 요소만 확인됨 | 무엇이 미확인인지 명시 |

gil 공용 인용 4분류(VERIFIED / SECONDARY / 미확인·재확인 필요)와 정합: 1차 자료=VERIFIED, 산업보고서·2차 확인=SECONDARY(원문 재확인 필요 병기), [미검증]=미확인.

## 3. 표기 형식

- 본문: "일본 비만치료제 시장은 X조 원 규모다 (기관, 2026, 링크)"
- 표: 각 행에 근거 파일명 또는 출처 열 필수
- 내부 자료와 외부 정보가 다르면: "내부 메모는 A, 외부 소스는 B — 차이 원인 확인 필요" 형식으로 명시

## 4. 조사 비용 통제 (gil 공통 규칙 정합)

- 원문 확보 시도는 정보원 3곳·총 5회 상한 — 초과 시 SECONDARY로 기록하고 진행
- 예상 소요 8분 초과 시 착수 전 ⚡Quick(3~5분)/◐Standard(8~12분)/◆Deep(20분+) 3모드를 1회 고지하고 사용자 선택. 무인 실행은 Standard
- 조사와 문서화를 함께 요구받으면 "①조사 확정 → ②문서화" 2단 분리를 먼저 제안
