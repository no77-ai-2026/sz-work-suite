# 계약 유형별 검토 프리셋 (사례 축적형)

> 사용법: 검토 대상 계약의 유형을 판별해 해당 프리셋의 체크포인트를 기본 검토 축으로 쓴다.
> **사례 축적**: 사용자가 "이 검토를 프리셋 사례로 추가해줘"라고 하면, 해당 유형의 `### 축적 사례` 아래에 [날짜 · 계약 개요 1줄 · 쟁점 → 처리 → 교훈] 3줄 형식으로 덧붙인다(덮어쓰기 금지). 사례가 5건 이상 쌓인 유형은 체크포인트 개정을 제안한다.

## 1. 용역(서비스) 계약
- 핵심 체크: 업무 범위(SOW)의 특정성 / 검수 기준·기한과 간주승인 조항 / 대금 지급 시기·지연이자 / 지식재산권 귀속(결과물 vs 기성 자산) / 재위탁 허용 여부 / 책임 상한(대금 총액 연동인지)
- 독소조항 주의: 무제한 하자보수, 포괄적 경업금지, 일방적 범위 변경권
### 축적 사례
- (아직 없음)

## 2. 공급·매매 계약
- 핵심 체크: 품질 기준·검사 방법 / 납기와 지체상금 요율 / 위험 이전 시점(인도 조건, Incoterms 여부) / 하자담보 기간 / 대금 조정 조항(원자재 연동) / 해제 사유의 상호성
- 독소조항 주의: 무기한 품질보증, 일방적 발주 취소권, 전량 구매 강제
### 축적 사례
- (아직 없음)

## 3. 투자 계약 (주식·전환사채 등)
- 핵심 체크: 밸류에이션·지분율 산정 / 우선주 권리(청산우선·전환·상환) / 이사 지명·동의권 목록의 범위 / 창업자 주식 제한(락업·베스팅) / 태그얼롱·드래그얼롱 / 진술보증 범위와 손해배상 상한
- 독소조항 주의: 과도한 동의권(일상 경영 침해), 무제한 진술보증, 창업자 연대보증
### 축적 사례
- (아직 없음)

## 4. 근로·용역위임 계약
- 핵심 체크: 근로자성 판단 요소(지휘감독·전속성) / 근로시간·연장수당 / 경업금지의 기간·지역·대상 합리성 / 영업비밀·발명 귀속 / 해지 사유·절차
- 독소조항 주의: 포괄임금 남용, 퇴직 후 무보상 경업금지, 위약벌 예정
### 축적 사례
- (아직 없음)

## 5. 라이선스·IP 계약
- 핵심 체크: 허락 범위(독점/비독점·지역·기간·분야) / 로열티 산정 기준과 감사권 / 개량 기술 귀속 / 침해 대응 의무 주체 / 종료 후 존속 조항
- 독소조항 주의: 그랜트백 강제, 무제한 최혜 대우, 종료 후 무기한 비밀유지
### 축적 사례
- (아직 없음)
