# 조사 심도 3모드 + 소요 사전 고지 (법무 4스킬 공용 정본)

> 적용 대상: contract-review · nda-triage · legal-risk · compliance-check + `legal-review-coordinator`
> 신설 사유(v1.7.2): 인용 5규칙의 "원문 1순위 + 회색지대 금지"가 접근 불가 정보원(lex.uz 등)과 만나면
> 재시도 폭주 → 장시간 소요 → 성과 없음으로 끝난다. 실측 사례: UZ 노동법 질의 1건에 원문 시도 132회·21분,
> 상당수 "미확인" 종료. 심도를 사용자가 **착수 전에** 고르게 해서 비용을 통제한다.

## 1. 3모드 정의

| 모드 | 트리거 | 실행 방식 | 예상 소요 | 허용 인용 등급 |
|---|---|---|---|---|
| ⚡ **Quick** (1차 답변) | "빠르게", "1차 답변만", "대략", "간단히" | 서브에이전트 위임 없이 **메인 세션에서 검색 5~6회**로 종료 | **3~5분** | SECONDARY 허용 |
| ◐ **Standard** (기본값) | 별도 지정 없음 | 2차 출처(실무 해설·공식 DB) 중심 + **핵심 조문만** 원문 시도 | **8~12분** | VERIFIED + SECONDARY |
| ◆ **Deep** (원문 대조) | "원문 대조", "조문 확인해줘", "정확히", 계약 서명·분쟁·인허가 등 확정 사안 | 관할 1순위 원문 전수 대조, 서브에이전트 병렬 가능 | **20분+** | VERIFIED 전용 |

- 모드 판정은 **1단계(요청 유형 확인)와 동시에** 수행한다.
- 사용자가 모드를 명시하지 않았고 예상 소요가 **8분 이하**면 고지 없이 Standard로 진행한다.

## 2. 사전 고지 규칙 (HARD)

예상 소요가 **8분을 초과**하거나 **서브에이전트 위임·3단계 이상 체인**이 필요하면,
**착수 전에 1회** 아래 형식으로 고지하고 선택을 받는다. 고지 없이 장시간 작업을 시작하지 않는다.

```
⏱ 이 질의는 원문 대조까지 하면 20분 이상 걸립니다.
 ⚡ 빠르게(3~5분): 2차 출처 기준 1차 답변 + "⚠ 원문 재확인 필요" 표시
 ◐ 표준(8~12분, 권장): 핵심 조문만 원문 대조, 나머지는 2차 출처
 ◆ 원문 대조(20분+): 전 조문 VERIFIED 목표 (접근 불가 시 미확인으로 남을 수 있음)
어느 쪽으로 진행할까요? (응답 없으면 표준으로 진행합니다)
```

- 고지는 **1회만** 한다. 중간에 다시 묻지 않는다.
- 무인·예약 실행(사용자 부재) 상황에서는 묻지 말고 **Standard로 진행**하고, 산출물 머리에 "표준 모드로 진행" 1줄을 남긴다.
- 작업 중 예상보다 오래 걸릴 징후(원문 확보 실패 누적, 재시도 상한 도달)가 보이면 **중단하고 현재까지 결과로 답한 뒤** 승격 여부를 묻는다.

## 3. 문서 체인 분리 (HARD)

`research-assistant → legal-risk → docx-generator → ai-slop-reviewer → humanize-korean` 같은
**5단 순차 체인은 조사 단계보다 더 오래 걸린다.** 조사와 문서화를 한 번에 요청받으면 다음을 먼저 제안한다.

```
1단계) 조사 답변을 채팅으로 먼저 확정  ← 여기서 사용자가 내용 검수
2단계) 확정된 내용으로 문서만 생성      ← docx-generator → ai-slop-reviewer → humanize-korean
```

- 사용자가 "이 내용으로 DOCX만"이라고 지시하면 **뒷단 2~3단계만** 실행하고 조사 단계를 재실행하지 않는다.
- 조사가 이미 끝난 사안에서 문서 형식만 바꾸는 요청은 **항상** 뒷단만 실행한다.
- 체인을 통째로 돌려야 하면 그 사실과 예상 소요를 §2 형식으로 먼저 고지한다.
