# 정보원 접근 실무 노트 (법무 4스킬 공용 정본)

> 적용 대상: contract-review · nda-triage · legal-risk · compliance-check + `legal-review-coordinator`
> 목적: "원문 1순위" 규칙이 **기술적으로 접근 불가능한 정보원**을 만났을 때의 정지 조건을 정한다.
> 이 문서가 없으면 에이전트는 대체 엔드포인트를 무한히 순회한다(실측: 1건에 132회 시도·21분·성과 없음).

## 1. 재시도 상한 (HARD)

- 동일 조문의 **원문 확보 시도는 정보원 3곳·총 5회**까지. 초과 즉시 중단한다.
- 중단 후에는 2차 출처로 전환해 `⚠ 원문 재확인 필요`(SECONDARY 등급)로 표기하고 **작업을 계속 진행**한다.
- 다음 우회는 **금지**한다: PDF 엔드포인트 추측, 미러·캐시 사이트, 언어판(우즈벡어↔러시아어↔영어) 순회 재시도, 검색어만 바꾼 동일 페이지 반복 요청.
- 원문 확보 실패는 **오류가 아니라 정상적인 조사 결과**다. 실패를 이유로 답변을 미루지 않는다.

## 2. 관할별 접근 특성

| 관할 | 원문 접근성 | 실무 지침 |
|---|---|---|
| **한국** | 양호 | korean-law MCP(search_law·get_law_text·search_decisions) → law.go.kr. **본 문서의 재시도 상한을 한국 질의에 확대 적용하지 말 것** — Deep 모드도 저비용으로 가능하다. |
| **우즈베키스탄** | **제약 있음(아래 §3)** | 원문 시도는 상한 내에서 1회 시도하고, 실패 시 2차 출처 기반 SECONDARY로 진행 |
| 기타 국가 | 가변 | 공식 DB 1회 시도 → 실패 시 SECONDARY, '추정' 표기 |

## 3. lex.uz 제약 (확인된 사실)

- **lex.uz는 조문 본문을 JavaScript로 렌더링한다.** WebFetch로 가져오면 **목차·메타데이터만** 반환되고 조문 텍스트는 비어 있다.
- PDF 다운로드 엔드포인트, 미러 사이트, 우즈벡어판/러시아어판 전환 모두 같은 이유로 대부분 실패한다.
- 따라서 **UZ 조문은 자동 fetch만으로는 VERIFIED가 되기 어렵다.** 이를 전제로 조사 계획을 세운다.

**원문이 반드시 필요할 때의 정공법(순서대로):**

1. 사용자에게 **lex.uz 해당 페이지 본문을 붙여넣어 달라고 요청**한다 (가장 빠르고 확실).
2. 브라우저 도구(claude-in-chrome 등)로 렌더링 후 텍스트를 읽는다 — 사용자 승인 필요.
3. 위 둘 다 불가하면 2차 출처 + `⚠ 원문 재확인 필요`로 종료하고, 검토 의견에 "확정 전 원문 대조 필요" 항목을 남긴다.

## 4. UZ 2차 출처 우선순위

| 순위 | 출처 | 성격 |
|---|---|---|
| 1 | norma.uz · kadrovik.uz · buxgalter.uz | 실무 해설(노동·회계·세무). 조문 번호와 개정일이 함께 실리는 경우가 많아 대조 단서로 유용 |
| 2 | regulation.gov.uz | 입법예고·개정 동향(§ 인용 5규칙 4번 블록의 근거) |
| 3 | parliament.gov.uz · gazeta.uz · spot.uz · kun.uz | 통과·시행 사실 확인 |
| 4 | KOTRA 해외경제정보·세계법제정보센터 | 한국어 참고. **한국어 자료 단독 인용 금지** — 반드시 위 1~3과 교차 확인 |

## 5. 실패 기록 의무

원문 확보에 실패한 조문은 산출물 말미에 다음 형식으로 남긴다.

```
### 원문 재확인 필요 항목
| 법령·조문 | 확인에 사용한 2차 출처 | 실패 사유 |
|---|---|---|
| 「Mehnat kodeksi」 제N조 | norma.uz 해설(2026-07-20) | lex.uz JS 렌더링으로 본문 회수 불가 |
```
