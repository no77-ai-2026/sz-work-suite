# 법률 인용 5규칙 + 관할 프로필 (법무 4스킬 공용 정본)

> 적용 대상: contract-review · nda-triage · legal-risk · compliance-check (전 스킬이 본 문서를 정본으로 참조)
> 원천: 우즈벡 수퍼로이어 프로젝트 방법론(사용자 저작, GIL 오리지널) + 인용 무결성 분류
> 함께 볼 정본: `research-depth-modes.md`(심도 3모드·소요 사전 고지) · `source-access-notes.md`(정보원 접근 제약·재시도 상한)

## 인용 5규칙 (HARD)

1. **문장별 근거 조문** — 법적 판단·설명이 담긴 각 문장 바로 아래(또는 괄호)에 근거 법령·조문을 제시한다. 법령명은 원어 병기: 「상법」 제530조 / 「Об обществах с ограниченной ответственностью」(유한책임회사법) 제N조.
2. **말미 출처 리스트** — 답변·문서 끝에 참고한 모든 법령·판례·해설의 **실제 링크**(law.go.kr·lex.uz 등)를 리스트로 붙인다.
3. **현행성 검증** — 훈련 지식만으로 조문을 단정하지 않는다. 답변 전 반드시 조회(MCP/웹)로 현행 여부·개정 이력을 확인한다. 모든 인용은 **4분류**로 표기한다(v1.7.2 개정).

   | 등급 | 의미 | 처리 |
   |---|---|---|
   | **VERIFIED** | 공식 원문(법령 DB) 대조 완료 | 그대로 사용. Deep 모드에서 유일하게 허용되는 등급 |
   | **SECONDARY** | 공신력 있는 2차 출처로 확인, 원문 미대조 | `⚠ 원문 재확인 필요` 병기 후 사용. Quick·Standard 모드에서 허용 |
   | **NOT_FOUND** | 2차 출처로도 확인 실패 | 산출물에서 제거 |
   | **MISMATCH** | 출처 간 내용 불일치 | 수정 후 재검증, 해소 전까지 단정 금지 |

   훈련 지식만으로 쓴 문장은 어떤 등급도 받을 수 없다(= 쓰지 않는다). **SECONDARY 신설 사유**: 종전 3분류는 회색지대를 금지해, 원문 접근이 기술적으로 막힌 관할(lex.uz 등)에서 유효한 2차 출처 정보까지 NOT_FOUND로 폐기되고 에이전트가 원문 확보를 무한 재시도하는 문제를 낳았다(실측 132회·21분·성과 없음). 재시도 상한은 `source-access-notes.md`, 등급별 허용 범위는 `research-depth-modes.md`를 따른다.
4. **개정 동향 블록** — 사안 관련 법령의 개정·입법 진행 상황을 조사해 [현행 → 개정 논의 → 진행 단계 → 예상 시행] 순으로 제시한다. 확인되지 않으면 "현재 확인되는 개정 논의 없음(조사일 기준)"을 명시한다.
5. **불확실성·비변호사 고지** — 원문을 직접 확인하지 못한 내용은 '추정'임을 표시하고, 현지/한국 자격 변호사 검증 필요 사항을 구분 표기한다. 중요 사안에는 "본 검토는 법률 자문이 아니며 최종 판단은 자격 변호사 확인이 필요"를 고지한다.

## 관할 프로필 (질의 관할 자동 판별 후 1순위 정보원 사용)

| 관할 | 조문 확인 1순위 | 개정 동향·해설 | 비고 |
|---|---|---|---|
| **한국** | korean-law MCP(search_law·get_law_text·search_decisions) → 국가법령정보센터 law.go.kr | 의안정보시스템·법제처 입법예고, 주요 법률 매체 | MCP 미연결 시 law.go.kr 웹 조회 |
| **우즈베키스탄** | lex.uz (러/우즈벡 원문) — **단, 조문 본문이 JS 렌더링이라 자동 fetch로는 회수 불가**. 시도 상한 준수 후 2차 출처(norma·kadrovik·buxgalter)로 전환 | regulation.gov.uz(입법예고)·parliament.gov.uz·norma.uz(실무 해설)·kun.uz/gazeta.uz/spot.uz(매체) | 한국어 참고는 KOTRA·세계법제정보센터. 원문 미대조 항목은 SECONDARY 표기 |
| 기타 국가 | 해당국 공식 법령 DB 웹 조회 | 현지 정부 공보·주요 매체 | 확인 불가 항목은 '추정' 표기 |

관할이 섞인 사안(예: 한-UZ 합작)은 관할별로 섹션을 나눠 각자의 정보원으로 검증한다.

**정보원 접근 실패 시**: 원문 확보 시도는 정보원 3곳·총 5회를 넘기지 않는다. 상한 도달 시 즉시 SECONDARY로 전환해 작업을 계속하고, 실패 항목은 산출물 말미 "원문 재확인 필요 항목" 표에 남긴다. 상세는 `source-access-notes.md`.
