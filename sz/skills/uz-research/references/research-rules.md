# 조사 규칙 정본 — 인용 4분류·접근 상한·2단 분리

## 인용 4분류
| 태그 | 조건 | 표기 |
|---|---|---|
| VERIFIED | 1차 출처(T1) 원문에서 직접 확인 | 출처 URL + 발표일 |
| SECONDARY | 2차 출처(T2/T3)로만 확인 | "⚠ 원문 재확인 필요" 병기 |
| NOT_FOUND | 상한 내 확인 실패 | 추정 서술 금지, 시도 이력 1줄 |
| MISMATCH | 출처 간 값 불일치 | 양쪽 값·출처 병기, 판단은 사용자 |

## 원문 접근 상한 (HARD)
- 한 항목의 원문 확보 시도: 정보원 최대 3곳, 시도 총 5회.
- PDF·미러·언어판 순회로 상한을 우회하지 않는다.
- 상한 도달 → SECONDARY 전환 + "원문 미확인" 명시.

## 소요 고지 (HARD)
- 예상 8분 초과 시 착수 전 1회 고지: 예상 소요 + 모드 선택지(⚡/◐/◆).
- 진행 중 재시도 누적·상한 도달 징후가 보이면 멈추고 현재까지 결과로 보고.

## 조사·문서화 2단 분리
① 조사 확정(표로 보고) → ② 사용자 확인 후 "이 내용으로 문서만" 산출. 조사와 보고서 작성을 한 번에 몰아 진행하지 않는다.
