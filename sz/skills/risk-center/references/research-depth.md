# 조사 심도·정보원 접근 규칙 (정본 요약 — 전체는 sz:uz-research references)

## 1) 인용 등급 4분류
| 등급 | 의미 | 처리 |
|---|---|---|
| VERIFIED | 1차 원문(공식 발표·법령 DB) 대조 완료 | 그대로 사용 |
| SECONDARY | 공신력 있는 2차 출처로 확인, 원문 미대조 | `⚠ 원문 재확인 필요` 병기 후 사용 |
| NOT_FOUND | 2차 출처로도 확인 실패 | 산출물에서 제거, 시도 이력 1줄 |
| MISMATCH | 출처 간 불일치 | 양쪽 값·출처 병기, 단정 금지 |

## 2) 원문 확보 재시도 상한 (HARD)
동일 항목 원문 확보 시도는 **정보원 3곳·총 5회**까지. `lex.uz`는 JS 렌더링으로 자동 fetch 시 목차만 회수되므로 상한 도달 시 2차 출처(norma.uz·kadrovik.uz·buxgalter.uz → regulation.gov.uz → gazeta/spot/kun.uz)로 전환해 SECONDARY 표기 후 **작업을 계속한다**. PDF 엔드포인트 추측·미러·언어판 순회 금지. 원문이 꼭 필요하면 사용자에게 페이지 텍스트 붙여넣기를 요청.

## 3) 조사 심도 3모드 (HARD)
| 모드 | 트리거 | 방식 | 소요 |
|---|---|---|---|
| ⚡ Quick | "빠르게" | 검색 5~6회, 핵심만 | 3~5분 |
| ◐ Standard | 기본 | 2차 중심 + 핵심 원문 시도 | 8~12분 (주간 갱신 전수 스윕은 20~40분) |
| ◆ Deep | "원문 대조" | 원문 전수 대조(VERIFIED 전용) | 20분+ |
8분 초과 예상 시 착수 전 1회 고지·선택. 무응답 시 Standard로 진행하고 산출물 머리에 `조사 모드: …(YYYY-MM-DD 조회)` 표기. 재시도 누적 시 멈추고 현재까지 결과로 보고.

## 4) 조사·문서화 2단 분리 (HARD)
①조사 확정(표) → ②"이 내용으로 문서만" 지시 후 `sz:docx-generator` → 등급별 검수.

## 5) 원문 확보 실패 항목은 산출물 말미에 표로
`| 항목 | 확인에 사용한 2차 출처 | 실패 사유 |`
