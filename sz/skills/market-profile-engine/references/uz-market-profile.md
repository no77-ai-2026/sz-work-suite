# UZ/CIS 시장 프로필 (사전 구축 원본)

> 우즈베키스탄/CIS 크리에이티브 현지화 기준 프로필. 신규 CIS 국가 생성 시 출발점으로 사용.

## 언어
- 주: 러시아어(ru), 병기: 우즈벡어(uz). 표기 = 키릴/라틴 병존(채널 관습 확인).
- 카피는 RU/UZ 병렬. 숫자·통화 = сум(UZS), 천단위 구분 관습 확인.

## 문화 차원
- 신뢰 단서: **정품(оригинал)·적합성 인증**, 지인·커뮤니티 추천 비중 큼.
- 사회적 증거: 후기·평점 + 오프라인 평판.
- 종교: 이슬람 다수 → 할랄·표현 금기 고려. 색·상징 금기는 개별 확인.

## 소비자 행동
- 결제: **Payme·Click·Uzum Nasiya(할부)**. 착불 현금(наложенный платёж) 관습.
- 배송: **BTS·Yandex Delivery**. 지역 편차 큼.
- 가격 민감도 높음 → 혜택·할부 소구 유효.

## 산업 규범·규제
- 최상급·과장·의학 효능 표현 절제. 화장품·식품·의약외품 표시의무 확인.
- 인증(적합성 인증 등) 배지 슬롯 노출이 신뢰에 기여.

## 플랫폼 규범
- Uzum Market(최대 이커머스)·Yandex·OLX(C2C)·Telegram(채널·봇 커머스).
- 각 채널 이미지 규격·금지 규정은 해당 gil 커머스 스킬 가이드 참조.

## 크리에이티브 조판
- 비라틴(키릴·우즈벡) → renderMode=overlay 기본. 이미지는 배경만 생성 후 카피 후조판.

## 검수
- 1차 리서치 + 현지 전문가 검수 전제. 불확실 항목은 단정 금지.
