## 1. 판형

| 항목 | 값 |
|---|---|
| 용지 | A4 세로 (11906 × 16838 twips) |
| 여백 상/하 | 1418 twips (2.5cm) |
| 여백 좌/우 | 1134 twips (2.0cm) |
| 머리말/꼬리말 거리 | 851 twips (1.5cm) |
| 본문 폭 | 9638 twips (17.0cm) |
| 본문 가용 높이 | 약 700pt |
| 폰트 | **BatangChe** 단일 (ascii/eastAsia/hAnsi 모두) |
| 꼬리말 | `- 1 -` 가운데, 12pt |

BatangChe는 고정폭이다. 한글·한자·전각기호 = 1em, 라틴·숫자 = 0.5em.
주석 x좌표 계산이 이 성질에 의존한다.

## 2. 문단 계층과 들여쓰기

| level | 마커 | firstLine (twips) | 크기 | 굵기 | 용도 |
|---|---|---|---|---|---|
| `head` | `□ ` | 0 | 14pt | **굵게** | 대항목 |
| `dash` | `- ` | 301 (0.53cm) | 14pt | 보통 | 중항목 |
| `dot` | `·` | 420 (0.74cm) | 14pt | 보통 | 소항목 |
| `arrow` | `→ ` | 560 (0.99cm) | 14pt | 보통 | 결론·조치 |
| `star` | `※ ` | 560 | 14pt | 보통 | 유의·부연 |
| `tri` | `▷ ` | 700 (1.23cm) | 14pt | 보통 | 세부 분기 |
| `cont` | (없음) | 560 | 14pt | 보통 | 앞줄 이어쓰기 |

공통: 줄간격 `line=240 lineRule=auto` (100%), 문단 뒷여백 `after=180` (9pt).
`head`도 동일한 180을 쓴다. 개별 조정이 필요하면 블록에 `space_after`(twips)를 준다.

**제목**: 20pt / 굵게 / 밑줄 / 가운데 / `after=560` (28pt).
제목 뒷여백은 `title_space_after`로 조정 가능(원본은 560~720 사이).

## 3. 주석 텍스트박스

원본의 위치 규칙은 "설명 대상 단어의 시작 x좌표, 그 줄 바로 아래 줄간 공백"이다.
원본 12개 좌표로 검증했다(오차 평균 0.09cm).

| 속성 | 값 |
|---|---|
| 색상 | `0000FF` |
| 크기 | 10pt |
| 자간 | `w:spacing val="-12"` (-0.6pt) |
| 접두 | `* ` (스크립트가 없으면 자동으로 붙임) |
| 도형 | 채우기 없음, 테두리 없음, `wrapNone`, `allowOverlap=1` |
| 수평 앵커 | `relativeFrom="margin"`, 계산된 절대 오프셋 |
| 수직 앵커 | `relativeFrom="paragraph"`, `posOffset=200000` EMU (0.56cm) |
| 여유폭 | 계산 폭 + 220000 EMU |

한 줄에 주석이 여럿이면 스크립트가 왼쪽부터 배치하며 최소 간격 90000 EMU를 둔다.
미세 조정이 필요하면 블록의 각 주석에 `dx_cm` / `dy_cm`(cm 단위, 음수 가능)을 준다.

### 제목 주석

최상위 `title_notes`로 제목 아래에도 붙일 수 있다(W36 확정본의 `* Atradius社`).
제목은 가운데정렬이므로 x좌표는 **제목 시작점 기준**으로 계산한다.
`anchor`를 주면 제목 안 해당 단어 아래, 생략하면 제목 왼쪽 끝에 맞춘다.

```json
{"title": "SEUZ, 채권 Top-up 보험 헷징 가입",
 "title_notes": [{"text": "Atradius社"}]}
```

상대 회사명·기관명은 제목에 넣지 말고 여기로 뺀다.

## 4. 표

| 속성 | 값 |
|---|---|
| 들여쓰기 | `tblInd=560` twips |
| 셀 글자 | 12pt, 가운데 정렬, 세로 가운데 |
| 헤더행 | 굵게 + 하단 `single sz=12` 굵은 선 |
| 캡션 | 표 위 가운데 12pt, `< … >` 또는 `[ … ]`로 감쌈 |

표 뒤에는 빈 문단이 자동으로 하나 들어간다(원본 관습).

블록에 `"borders": "grid"`(기본, 전체 실선 · W18·W20형) 또는
`"borders": "minimal"`(헤더 하단선만 · W33형)을 줄 수 있다.

## 5. JSON 입력 스키마

```jsonc
{
  "title": "SEUZ, 우즈벡 할부 규제 도입 관련",   // 필수
  "footer": "- 1 -",                            // 선택, 기본 "- 1 -"
  "title_space_after": 560,                     // 선택, twips
  "blocks": [
    { "level": "head", "text": "도입 배경" },

    { "level": "dash",
      "text": "대통령령으로 「할부결제 서비스 개선 조치」서명 (8/14日)",
      "notes": [
        { "anchor": "「할부결제",                // 본문에 실존하는 문자열
          "text": "대통령령(΄26.8.14 서명) → ΄27.1月 시행",
          "dx_cm": 0,                            // 선택, 미세조정
          "dy_cm": 0 }                           // 선택
      ]
    },

    { "level": "dot",
      "text": "분기 매출 5억 숨 초과 + 할부 비중 50% 이상 사업자는 등록 의무",
      "notes": [
        { "anchor": "5억 숨",  "text": "42K$" },
        { "anchor": "사업자는", "text": "제조업 제외" }
      ]
    },

    { "type": "table",
      "caption": "< 당사/우즈벡 정부/대학 間 R&R >",
      "rows": [
        ["구 분", "당 사", "우즈벡 고용부"],
        ["강 의 장", "-", "○(AI Course)"]
      ]
    }
  ]
}
```

축약 표기도 받는다.

- `"note": "우즈벡 중앙은행"` + `"anchor": "CBU"` — 주석 하나짜리
- `"notes": ["제조업 제외"]` — 문자열만 주면 앵커 없이 줄 끝 배치
- `text` 앞에 마커(`□`, `-`, `·`)를 직접 붙이지 않는다. 스크립트가 붙인다.

## 6. 스크립트 사용법

```bash
python3 scripts/build_report.py input.json 출력.docx --md 미리보기.md
```

표준 출력으로 점검 결과를 낸다.

```
[줄넘침]     본문이 한 줄을 넘김 → 해당 줄 압축
[주석넘침]   주석이 우측 여백 초과 → 주석 축약 또는 앵커 앞으로 이동
[앵커없음]   anchor 문자열이 본문에 없음 → 줄 끝에 배치됨
[분량초과]   1페이지 초과 → 본문 줄 삭감
[분량주의]   가용 높이의 93% 초과 → 여유 없음
```

분량 추정은 본문 한 줄 18pt + 뒷여백, 제목 26pt, 표 행당 20pt 기준이다.
실제 Word 렌더링과 ±1줄 정도 차이가 날 수 있으므로 경고가 뜨면 여유를 둔다.

## 7. 구형 판형 (참고)

W16~W26 문서는 여백이 다르다. 사용자가 구형으로 맞춰 달라고 하면
`scripts/build_report.py` 상단 상수를 이 값으로 바꾼다.

```
MARGIN_TOP = 1276, MARGIN_BOTTOM = 1440
MARGIN_LEFT = 1134, MARGIN_RIGHT = 1274
HEADER_DIST = FOOTER_DIST = 720
꼬리말 없음, 제목 뒷여백 720
```

통합본에 끼워 넣는 발췌본(SIC·W28·W31·W32)은 또 다르다.
여백 1134 전방향, 제목이 `6. SEUZ, …` 형태로 14pt 좌측 정렬,
꼬리말 `- 9/9 -`. 이 형태가 필요하면 사용자에게 통합본 내 페이지 번호를 물어본다.
