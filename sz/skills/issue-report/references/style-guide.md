# 문체 가이드

원본 18건에서 뽑은 실제 문장을 기준으로 한다. 이 문체는 임원 보고용으로
"읽는 시간을 최소화"하는 것이 목적이라, 일반 공문체와 다르다.

## 1. 종결 — 명사형

서술어를 명사나 한자 한 글자로 끝낸다. `~합니다`, `~하였음`, `~할 예정입니다`는
쓰지 않는다.

| 뜻 | 쓰는 형태 |
|---|---|
| 예상된다 | `~ 예상` |
| 완료했다 | `~ 완료` / `~完` |
| 진행 중이다 | `~ 진행中` / `~中` |
| 필요하다 | `~ 필요` / `~必` |
| 가능하다 | `~ 가능` / `~可` |
| 추진한다 | `~ 추진` |
| 검토한다 | `~ 검토` |
| 하기로 했다 | `~ 결정` / `~ 확정` |
| 요청했다 | `~ 요청` |
| 없다 | `~ 無` |
| 이미 ~했다 | `旣~` |

실제 문장:

```
- 전자 제품 시장에 활성화된 할부 매출/판매 위축 예상
- 기존 공장의 설비/장비 이전 활용으로 추가 투자는 無
·설비 이전, 장비 재설치 및 작업자 교육 완료(~W22)
·全 모델 대상 IEC 리포트 확보 및 제출 프로세스 진행中
·현재 4개모델만 샘플 제공, 잔여모델 추가제공必
```

`- 대 상 : 18∼30세 청년`처럼 **항목명 : 값** 형태도 자주 쓴다.
항목명이 두 글자면 `대 상`, `금 액`, `기 간`처럼 가운데를 벌려 정렬을 맞춘다.

## 2. 한자 약어

해당 맥락이 나오면 쓴다. 억지로 밀어 넣지는 않는다.

| 한자 | 뜻 | 용례 |
|---|---|---|
| 中 | 중 / ~하는 중 | `진행中`, `΄26년中`, `307社 중` |
| 內 | 안 | `10일內`, `2주內`, `법인內` |
| 外 | 밖 | `보험사 요청 거래선外` |
| 前 / 後 | 전 / 후 | `개막前`, `등록후`, `교육 개시後` |
| 上 / 下 | 상 / 하 | `등기부上`, `현행법上`, `조건下` |
| 旣 | 이미 | `旣수검`, `旣편성예산` |
| 全 | 전체 | `全제품`, `全 모델` |
| 低 / 高 | 낮음 / 높음 | `연체 이력低`, `유동인구多`, `金의존도高` |
| 多 | 많음 | `사진 촬영 과다`, `유동인구多` |
| 無 / 必 / 可 / 完 | 없음 / 필수 / 가능 / 완료 | `투자는 無`, `전환必`, `영업可`, `확인完` |
| 等 | 등 | `POSM 等`, `근태/복장 점검 等` |
| 名 / 件 / 社 | 명 / 건 / 사 | `총 7名`, `1.35만件`, `307社` |
| 案 | 안 | `□ 대응案`, `대응안 수립` |
| 計劃 | 계획 | `□ 향후 計劃` |
| 訴 | 소송 | `訴제기`, `집행 청구의 訴` |
| 年 / 月 / 日 | 연 / 월 / 일 | `΄26年`, `΄25.8月`, `(8/14日)` |
| 市 / 州 | 시 / 주 | `타슈켄트市`, `Jizzak州` |

## 3. 수치·단위·화살표

- 금액: `41K$`, `23.6M$`, `USD 32K/年`, `8.5조숨`, `2,060억UZS`
- 비율: `14.4%`, `72.6배`, `약 1.5개월`
- 인원/수량: `190만名`, `7.4K대`, `52개 점포`
- 증감: `매출 20~25%↑`, `가격 경쟁력↑`, `관리효율低`
- 전이/귀결: `→` (`Ba3 → Ba2로 1단계 상향`, `하원 통과 → 상원 심의中`)
- 범위: `18∼30세`, `΄23年 ∼΄25.6月`, `31~60일`
- 열거 구분: 가운데점 `·` (`판가·프로모션`, `관세·세금·인증`)
- 병렬 구분: 슬래시 `/` (`원금/할부수수료/총금액`, `영업 / Retail`)

**반올림** — 유효숫자 2~3자리. 원자료의 정밀도를 그대로 옮기지 않는다.
임원은 자릿수를 읽는 것이지 끝자리를 검산하지 않는다.

| 원자료 | 본문 |
|---|---|
| 9.115M$ | `9.1M$` |
| 12.215M$ | `12.2M$` |
| 273,450$ | `273K$` |
| 43,800,000$ | `43.8M$` |

정밀한 값이 근거로 필요하면 주석으로 뺀다. 단, **계약 확정 금액**
(`187.5K$`, `2.85%`)은 반올림하지 않는다.

## 4. 날짜와 연도

- 연도: `΄26年`, `΄25.8月`, `΄27.1月` — 앞 기호는 U+0384 `΄` (아포스트로피 아님)
- 날짜: 줄 끝 괄호로 `(8/14日)`, `(5/21)`, `(4/30)`
- 주차: `W25`, `~W26`, `(기존 W25에서 2주 지연)`
- 기간: `7/18日 ~ 7/27日`, `8/6∼9/19(약 1.5개월)`

## 5. 줄 설계

- 한 줄 평균 33자, 최대 45자. **줄바꿈 없이 한 줄에 끝낸다.**
- 한 문장이 길면 두 블록으로 쪼개지 말고, `cont` 레벨로 이어 붙인다.
  원본도 `- 우즈벡 법무부 차관 주관 주우 한국 기업인 간담회에 참석하여` /
  `현안 전달 및 관련 부처 담당자와 개별 면담 진행 (5/21)` 처럼 두 줄로 잇는다.
- 조사는 과감히 생략한다. `~에 대한` → `~ `, `~을 위하여` → `~ 위해` 또는 삭제.
- 접속사(`따라서`, `그러나`, `또한`)는 쓰지 않는다. 계층과 `→`가 대신한다.

## 6. 주석으로 뺄 것

본문에 부연이 들어가면 줄이 길어지고 읽는 속도가 떨어진다. 다음은 전부 주석행이다.

| 유형 | 주석 예 |
|---|---|
| 원어·약어 풀이 | `* Ministry of Employment and Poverty Reduction` |
| 환산액 | `* 약 658M$`, `* 42K$` |
| 근거 법령 | `* 내각결정 제324호 (ПКМ-324)`, `* 관세법 제100-106조` |
| 담당 부서 | `* 영업 / Retail`, `* 품질혁신/KD소싱/법무팀/SEUZ` |
| 조건·예외 | `* 제조업 제외`, `* 가산세無` |
| 출처 | `* KPMG`, `* Moody΄s` |
| 시점·기간 | `* 매일 18:00~, 약 2시간 진행`, `* ΄26.1月~` |
| 부가 수치 | `* 이용자 190만名, 35세 이하 63%`, `* 1 BRV = 44만 숨` |

## 7. 좋은 예 / 나쁜 예

**나쁜 예**
```
- 우즈베키스탄 중앙은행이 할부 사업자에 대한 등록 의무를 신설함에 따라,
  분기 매출이 5억 숨을 초과하고 할부 비중이 50% 이상인 사업자는 반드시
  중앙은행에 등록한 후에 영업을 할 수 있게 되었습니다. (단, 제조업은 제외)
```
3줄로 흐르고, 종결이 서술체이며, 예외 조건이 본문에 붙어 있다.

**좋은 예**
```
- 할부 운영 통제 신설로 할부 사업자는 중앙은행 등록후 영업可
 ·분기 매출 5억 숨 초과 + 할부 비중 50% 이상 사업자는 등록 의무
                                       * 제조업 제외
```

---

**나쁜 예**
```
- 법인은 2025년 8월에 이미 정기 세무조사를 받았으나, 우즈베키스탄 세법상
  매년 세무조사를 실시하는 것이 가능합니다.
```

**좋은 예**
```
- ΄25.8月 정기 세무조사를 旣수검 받았으나, 매년 세무조사는 가능
   * 우즈벡 세법상 국세 징수권 소멸 시효는 3년
```

---

**나쁜 예 (대응案)**
```
- 향후 리테일러를 포함한 거래선들의 가격 표기 방식 및 할부 표시 방식에
  대하여 점검할 수 있는 가이드를 마케팅팀과 법무팀이 함께 만들 계획입니다.
```

**좋은 예**
```
- 리테일러 등 거래선의 가격 표기 및 할부 표시 점검 가이드
   * 마케팅 / 법무
```

대응案 항목은 "무엇을 한다"만 남기고 담당 부서는 주석으로 뺀다.
문장 안에 부서명을 넣는 변형(`- ΄27년 세법 개정안 모니터링 (세무/법무)`)도
원본에 있으니, 부서가 짧으면 괄호로 본문에 두어도 된다.

## 8. 영문 약어는 한국어로 푼다

실무 메일에서 그대로 옮겨온 약어가 가장 자주 반려된다. 브로커·거래선이 쓰는
말과 법인이 보고하는 말은 다르다. 읽는 사람이 그 약어를 몰라도 뜻이 통해야 한다.

| 쓰지 않음 | 씀 |
|---|---|
| CL, Credit Limit | 여신 |
| ORL, On-Risk Letter | 보험 증권 서명본 |
| MP, Minimum Premium | 보험료 |
| Premium | 보험료 |
| UBO, Proposal form | (삭제) 보험 신청 |
| 부보 | 헷징 |
| 바인딩 오더 | 조건 확정 |
| 오퍼 접수 | 협상 |

MP와 premium을 굳이 구분하지 않고 **`보험료` 하나로 통일**한다. 구분이 실제로
의사결정에 걸리면 그때만 주석으로 뺀다.

살려 두는 영문: 고유명사(`Atradius社`, `Credendo社`, `S26FE`, `N-ERP`),
정착된 사업 용어(`Top-up`, `Open Risk`, `Seasonality`, `Cover`).

## 9. 능동 프레이밍

상대가 준 것을 받은 형태로 쓰면 법인이 수동적으로 읽힌다. 같은 사실을
법인이 주체인 문장으로 바꾼다.

**나쁜 예**
```
- 최초 오퍼(7/21日) : 9.115M$ 승인, 요율 3%, 최저 250K$
- 개정 오퍼(8/20日) : 7.9M$ 승인, 요율 2.85%, 최저 225K$
```

**좋은 예**
```
- 1차 협상 : 9.1M$, 보험료율 3.0%, 보험료 273K$ (7/21)
- 최종 협상 : 7.9M$, 보험료율 2.85%, 보험료 225K$ (8/20)
```

`오퍼 접수` → `협상`, `승인` → 조건 나열. `1차 / 최종` 대구로 놓아
개선폭(요율 3.0 → 2.85)이 눈으로 바로 잡히게 배치한다.

## 10. 부정형은 본문에 두지 않는다

`[미검증]`, `미수령`, `미산출`, `미확인`, `서면 미확인`, `지연中`을 본문에
나열하면 보고가 변명으로 읽힌다. 확인이 필요한 사항은 **향후 계획의 조치**로
바꿔 쓴다.

**나쁜 예**
```
□ 현 안
- 보험 증권 미발급으로 사용 개시 지연中
 ·상대사 리스크 인수 입장, 서면 미확인
- 정책 초안·약관 원문 미수령, 조건 요약표만 확보 [미검증]
```

**좋은 예**
```
□ 향후 운영 계획
- 9월중 보험 증권 서명본 수령후 Top-up 개시(N-ERP 등록)
```

예외 — 그 자체가 보고의 핵심이고 손실·법적 노출이 걸린 건은 본문에 남긴다.
그 경우에도 `□ 현 안`을 세우지 말고 영향 블록에 수치와 함께 쓴다.

## 11. 향후 계획의 세 요소

`모니터링`, `검토`, `지속 협의` 같은 말로 끝내지 않는다. 세 가지를 갖춘다.

```
- 9월중 보험 증권 서명본 수령후 Top-up 개시(N-ERP 등록)   ← ① 개시 조치 + 시스템 반영
- 보험 운영 실적 점검후 ΄27.6月 만기시 연장/재조정 여부 결정  ← ③ 의사결정 시점·선택지
 ·Top-up 보험 이용율(=추가 매출액/10개월/7.9M$*100)        ← ② 관리 지표 산식
```

① **개시 조치**는 사내 시스템 반영까지 적는다.
② **관리 지표는 산식을 그대로 노출**한다. 산식이 없으면 지표가 아니다.
③ **의사결정 시점과 선택지**를 명시한다(`만기시 연장/재조정 여부 결정`).

상대방(브로커·거래선)의 제안을 법인 계획으로 옮기지 않는다. 브로커가
"갱신 때 요율을 낮춰보자"고 한 것은 브로커 의견이지 법인이 갱신을
결정했다는 뜻이 아니다.

## 12. 띄어쓰기

한글 복합명사는 **띄운다**. 압축한다고 붙여 쓰면 확정본에서 교정된다.

| 붙여 씀 (교정 대상) | 띄어 씀 |
|---|---|
| 입증책임 | 입증 책임 |
| 감사법인 | 감사 법인 |
| 내각결정 | 내각 결정 |
| 규제기관 | 규제 기관 |
| 반복검사 | 반복적 검사 |
| 고용빈곤감소부 | 고용빈곤 감소부 |
| 인적자본 | 인적 자본 |
| 당사분담 | 당사 분담액 |

반대로 **한자 약어는 앞말에 붙인다**. `6,350건 中` → `6,350건中`,
`10일 內` → `10일內`, `적발 時` → `적발時`.

## 13. 프레이밍 — 법인 관점으로 쓴다

### 13.1 냉소적 해석을 쓰지 않는다

같은 사실도 구조의 결함으로 쓰면 보고서가 논평이 된다. 법인이 얻는 것으로 쓴다.

| 나쁜 예 | 좋은 예 |
|---|---|
| `사후 미납 적발時 책임은 감사 법인이 부담 → 리스크 전가 구조` | `사후 미납 적발時 책임은 감사 법인이 부담 → 기업 리스크 완화` |

### 13.2 사물 주어를 법인 주어로

| 나쁜 예 | 좋은 예 |
|---|---|
| `회신 내용은 Samsung Innovation Campus 협력 현황` | `법인은 Samsung Innovation Campus 협력 현황 제출 예정` |

개요 블록은 **외부 주체가 무엇을 하는가 → 법인이 무엇을 하는가** 순서로 둔다.

### 13.3 블록 첫 줄은 법인에게 무슨 의미인지 말한다

일반론·사회적 효과를 `-` 레벨에 나열하지 않는다. 법인 관점 한 줄을 세우고
나머지를 `·`로 내린다.

**나쁜 예**
```
□ 기대 효과
```
