# 아카이벌 실증연구 & Kill-fast 프로토콜 (Archival Empirical Playbook)

> 회계·재무·경제·경영 등 **관찰 데이터(archival) 실증연구**의 착수~식별 SOP. 실전에서 확립한 "Kill-fast, Signal-first" 원칙. RCT·메타분석 계열은 본 스킬 본문을, 텍스트 측정은 `nlp-measurement-quagmire.md`(research-analysis)를 참조.

## 0. 최상위 메타원칙 — "Kill-fast, Signal-first"

novelty만 좇다 null에 빠지지 마라. 대량 데이터 수집·집필 **전에** 세 가지를 먼저 확인한다.

1. **데이터 취득가능성** — 무료·표준·선행논문이 실제로 쓰는 데이터인가? (예: DART·KOSIS·GIR·SEC EDGAR·Compustat)
2. **효과가 실재하는가** — 최소 데이터로 핵심 상호작용을 돌려 **부호·유의성 + 기업고정효과(firm FE) 견고성**을 먼저 본다.
3. **효과의 선행문헌 선례** — 유사 효과가 이미 게재됐는가? 있으면 null 위험↓, 없으면 null 위험↑.

> 교훈: **"효과 선례 있음 + 데이터 무료·표준"이 novelty보다 게재확률을 좌우한다.** 13개 검정이 전부 null이 된 뒤에야 기각된 사례가 있는 반면, 배출 데이터 2파일만으로 예비검정→기업FE 견고 신호를 먼저 확인하고 착수해 게재 가능까지 간 사례가 있다.

## 1. Kill-fast 게이트 (새 실증주제 착수 직후, 대량작업 전)

절차:
1. **데이터 취득가능성부터** 확인.
2. **예비 신호검정(가장 중요)** — 최소 데이터로 핵심 상호작용 1개를 돌려 부호·유의성 + firm FE 견고성 확인.
3. **효과 선례** — 문헌에 유사효과 게재 여부.
4. **판정 게이트**:
   - (a) 신호 있고 firm FE 견고 → **본격 착수**.
   - (b) 신호 없음/횡단면만 → **여러 DV로 3~5개 빠른 검정** 후에도 null이면 **기각**.
   - (c) 측정 자체가 quagmire(측정 타당도 확보 불가) → **보류**.

**두 근본질문(착수 전 필수)**:
- **식별변수가 거시와 분리되는가?** (예: 특정 산업 사이클이 경기와 공변하면 순수 효과 식별 불가)
- **표본이 이론이 말하는 기업인가?** (목표 모집단과 실제 상장표본 불일치 시 검정력 소진)

## 2. 코퍼스·데이터-질문 정합 검증 (함정 #1)

**연구질문의 변수가 실제로 어느 문서/데이터에 있는지 소표본으로 먼저 확인.**
- 대표 기업 5~40개로 **base rate**(관심 현상의 출현빈도)를 먼저 잰다.
- 대량 수집(15GB 파싱 등)은 그 다음. **소표본 feasibility가 대량 수집보다 항상 먼저다.**
- 예: 특정 자율공시가 규제공시(사업보고서)엔 3%뿐이고 IR·실적발표에 있다는 사실은 소표본으로 30분 내 확인 가능.

## 3. 주제 bake-off (주제 재선정 시)

기각 후 다음 주제를 고를 때:
1. **후보 3개** 정의.
2. **병렬 리서치** — `Agent`(general-purpose) 3개 동시 실행 → 후보별 문헌·gap·저널·데이터 feasibility·go/no-go 점수(novelty·feasibility·journal 각 1~5).
3. **데이터 즉시점검** — 보유 원본에 각 후보 변수가 실제 존재하는지 스캔(예: 개발비가 표준재무엔 0%·주석에만 있으면 feasibility↓).
4. **위험조정 선택** — 점수 합만 보지 말고 **"효과 선례 + 데이터 표준성"으로 null 위험을 가중**. novelty 최고라도 측정 quagmire면 후순위.

## 4. 정책충격 DiD·원가행태 파이프라인 (표준 흐름)

```
표준재무(수집) → 원가/성과 패널(ABJ 등) → 외부 정책/처치 레이어(사용자 다운로드→마운트 처리)
  → 정규화 업체명 매칭 → 상호작용 DiD → 기업FE → event-study/stacked 강건성 → 정직한 프레이밍 → 집필
```
1. **기존 패널 재사용** — 이전 연구의 원가패널을 뼈대로. **새 논문은 처치/DV 레이어만 신규.**
2. **정책 처치변수** — 지정·시행이 연도별로 다르면 staggered(시차) 설계. `post = year ≥ 최초처치연도`.
3. **업체명 매칭** — `(주)/주식회사/㈜/공백 제거` 정규화 후 조인.
4. **모형(예: 원가경직성 ABJ)** — `Δln비용 = β1·Δln매출 + β2·(감소더미·Δln매출) + β3·(Post·감소더미·Δln매출) + 기업FE + 연도FE`, 기업클러스터 SE.
5. **자산 카탈로그** — 착수 시 기존 `papers/` 스캔해 재사용 패널·엔진·코퍼스를 자동발견. "새로 필요한 레이어만" 원칙.

## 5. Human-in-the-loop 게이트 (자동화 시 필수 승인지점)

① 코퍼스-질문 정합 판정 · ② 설계결정(DV·식별전략) · ③ 대량수집/외부데이터 다운로드 착수 · ④ 인과 vs 연관 프레이밍 확정 · ⑤ "최종본" 표기 전 Devil 통과. 나머지는 자동.

