# UZ 통관·보세창고 참조 노트 (요지 — 실무 적용 전 현행 확인 필수)

> 본 노트는 방법론·확인 포인트 정리이며 수치·기한은 개정될 수 있다.
> 적용 전 customs.uz·lex.uz(T1)에서 현행 확인 — sz:uz-research 절차 사용.

## 보세창고 (таможенный склад) 확인 포인트
- 보관 가능 기간과 연장 요건 / 기간 만료 시 처리(재수출·수입통관·국고 귀속)
- 반출입 절차·부분 반출 가능 여부 / 보세 상태에서의 가공·재포장 허용 범위
- 과세 시점(반출 시점 과세 원칙 여부)과 적용 환율 기준일
- 창고 운영자 요건·책임 범위 / 재고 보고 의무

## 수입통관 일반 확인 포인트
- HS 코드별 관세율·VAT·소비세 / TR(기술규정) 인증 대상 여부
- 통관 가격 산정(운임·보험 포함 기준) / 원산지증명에 따른 특혜세율(CIS FTA 등)
- 전자제품 특이사항: 인증·라벨링(UZ어 표기)·IMEI 등록 제도

## 서류 세트 표준
인보이스 · 패킹리스트 · 운송서류(B/L/AWB/CMR) · 원산지증명(CO) · 적합성 인증서 · 계약서 · (해당 시) 위생·전파 인증

## 자주 쓰는 RU 용어
таможенная декларация(세관신고서) · сертификат соответствия(적합성인증) · страна происхождения(원산지) · таможенная стоимость(과세가격)
