# UZ/CIS 듀얼 컨텍스트 — print-creative-builder

> 한국 표준 + 우즈베키스탄/CIS. 인쇄물·다국어.

## 다국어 인쇄
- RU/UZ 병렬 카피 → 후조판 필수(배경만 생성). 언어별 판형 분리 또는 병기 레이아웃.
- 키릴·라틴 글리프 커버 서체 확인(Inter/Noto Sans 대체 매핑). 한국어 병기 시 Pretendard/Noto Sans KR.

## 규격
- CMYK·300dpi·재단 3mm. 현지 인쇄소 규격·용지 관습 확인.
- 정품/적합성 인증 마크, 결제·연락 정보(Telegram·전화) 배치 슬롯.

## 소구·규제
- 신뢰·혜택 중심. 최상급·과장·의학 효능 표현 절제.

## 검수
- 최종 색·재단은 현지 인쇄소 프리플라이트 전제. 현지 전문가 문안 검수 권고.
