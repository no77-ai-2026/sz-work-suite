# UZ 듀얼 컨텍스트 — 문제 구조화 (uz-problem-solving)

한국 표준 + 우즈베키스탄(UZ)·CIS 듀얼 컨텍스트 적용 노트.

- **트리거(UZ)**: "muammoni tuzilmalash" (문제 구조화), "masala daraxti" (이슈 트리)
- **Problematic Fact의 데이터 제약**: UZ는 산업 통계·시장 데이터 공백이 커서 Fact Test 통과가 어려움 — 국가통계위(stat.uz), 중앙은행(cbu.uz), Uzum·OLX 등 플랫폼 공개 데이터, 국제기구(WB·ADB·EBRD) 보고서를 1차 대체원으로 사용하고, 미확보 시 [추정] 표기를 한국 케이스보다 관대하게 허용하되 검증 목록을 반드시 남긴다
- **이슈 문형의 현지 관행**: 국영기업·정부 이해관계자가 개입하는 의사결정이 많아, Actionable Direction에 "규제·인허가 경로"를 대안 축으로 자주 포함 (예: 직접 진출 vs 현지 파트너 vs 국영기업 협력)
- **Force at Work 절단면**: UZ 시장은 환율·수입 관세·물류(내륙국)·현금 결제 비중이 실동인인 경우가 많음 — 한국식 절단면(온·오프라인, 채널별)을 그대로 쓰지 말 것
- **Work Plan Source 열**: lex.uz(법령)는 자동 수집 제약이 있으므로 원문 시도 상한·2차 출처 우선 규칙(`sz:research-verify`의 source-grading 참조)을 따른다
