# UZ 듀얼 컨텍스트 — feedback-loop

> 한국 직장 커뮤니케이션 ↔ UZ 직장 커뮤니케이션

## 적용 원칙
이 스킬은 **한국 표준 + 우즈베키스탄 듀얼 컨텍스트**로 동작한다. 한국 사용자가 기본이며, UZ(타슈켄트·고려인·한·UZ 합작/ODA) 맥락 요청 시 아래를 반영한다.

## 도메인 컨텍스트
UZ 직장은 러시아어·우즈벡어 이중 언어 회의가 흔하고, 한·UZ 합작·KOICA/EDCF 사업에선 통역 경유 소통이 잦음. 위계·연장자 존중 문화가 강함. 한국식 두괄식 보고 + 현지 관계지향 절충 필요.

## 스킬 특화 노트
피드백 대비 — 트릴링구얼 환경 부정 피드백은 통역 경유 시 강도 왜곡 주의.

## 한·UZ 비교 (요지)
| 항목 | 한국 | 우즈베키스탄(UZ) |
|---|---|---|
| 언어 | 한국어 | 우즈벡어·러시아어(공용)·영어 제한 |
| 결제·금융 | 카드·계좌·간편결제 | Uzum Bank·Click·Payme·USD 현금 병행 |
| 데이터·규제 | data.go.kr·KOSIS·홈택스 | stat.uz·data.gov.uz·soliq.uz·cbu.uz |
| 채널 | 카카오·네이버 | Telegram(60%+)·Yandex |
