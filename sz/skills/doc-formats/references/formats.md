# 표준 문서 골격 5종 (v1.0 일반 템플릿 — 사내 양식 수집 후 교체 예정)

## 1. 공문 (Official Letter)
수신 / 참조 / 제목 / 본문(목적→내용→요청) / 첨부 / 발신일·발신 부서·직위·성명

## 2. 품의서 (Approval Request)
제목 / 기안 부서·기안자·기안일 / 1. 목적 / 2. 경위 / 3. 내용(항목·금액·기간 표) / 4. 요청사항(승인 문구) / 5. 첨부

## 3. 회의록 (Meeting Minutes)
회의명 / 일시·장소 / 참석자(직위 포함) / 안건별: 논의 요지 → 결정사항 / 액션아이템 표(No·항목·담당·기한) / 차기 일정

## 4. 주간보고 (Weekly Report)
기간 / 금주 실적(핵심 3~5) / 이슈·리스크(등급 표기) / 차주 계획 / 지원 요청

## 5. 출장보고 (Business Trip Report)
출장자·기간·지역 / 목적 / 일자별 활동 / 주요 결과·합의사항 / 후속조치(담당·기한) / 경비 요약

## KO/EN 병기 규격
- 문서 제목·표 헤더는 "한국어 (English)" 병기
- 본문 병기는 문단 병렬(KO 먼저) 또는 2단 표 — 문서당 한 방식만 사용
