# _Wiki 운영 헌법 (정본 — init 시 `_Wiki/OPERATIONS.md`로 복사)

> 나중의 나와 AI가 함께 읽는 문서. 왜 이렇게 나눴는지, 무엇을 어디에 넣는지의 판단 기준. 개정 시 하단 이력에 1줄.

## 1. 왜 이 구조인가
- **작업장↔위키 이원 구조**: 프로젝트 폴더는 작업장. 위키에는 재사용할 검증 지식만. 프로젝트 폴더는 어지러워도 되고, 위키는 깨끗해야 한다.
- **도메인 폴더 + 성숙도 frontmatter**: 지식은 도메인 축으로 찾는 게 자연스럽고, 성숙도를 폴더로 하면 승격 때마다 파일 이동으로 링크가 깨진다.
- **_inbox 분리**: 쌓는 행위(10초)와 배치 판단(주 1회)을 분리해 기록 마찰을 없앤다.

## 2. 배치 기준 — 무엇을 어디에
| 내용 | 위치 |
|---|---|
| 조직·개인 정체성(Why/How/What 압축본) — 선택 | `brand/` |
| 전략(무엇을 왜 만들 것인가) | `contents/strategy/` |
| 반복 절차·체크리스트·템플릿(어떻게 돌리는가) | `contents/ops/` |
| 재사용할 도메인 지식·통찰·방법론 | `wiki/<도메인>/` |
| 아직 판단 전인 신규 파일 | `wiki/_inbox/` |
| 원본 대화 로그 | `wiki/_inbox/logs/` |

**위키에 넣지 않는 것**: 일회성 산출물(보고서·제안서 완성본), 작업 중간 파일, 원본 자료 덩어리(요약·증류해서 넣는다), 민감한 개인 신상·금융 정보, 사내 기밀 원자료.

## 3. 도메인 정의 (init 시 조정 — 기본안)
| 도메인 | 범위 |
|---|---|
| uzbekistan | UZ 시장·규제·인증·유통·현지 비즈니스·거시 |
| accounting | 회계·세법(한국+UZ)·결산·감사 |
| risk-mgmt | 리스크 센싱 방법론·레지스터·대시보드 운영 교훈·검증 사례 |
| legal | 계약·컴플라이언스·법령 개정 이력 |
| hr | 채용·노무·규정·평가 |

새 도메인 신설은 파일 5개 이상 모였을 때만, `wiki/00_INDEX.md`에 1줄 등록과 함께.

## 4. 파일명 규칙
- `wiki/`: 날짜 없는 주제명(안정적 링크), 언더스코어. 예: `보세창고_운영규정_요지.md`
- `_inbox/`: `YYYYMMDD_주제.md` (배치 시 날짜 제거·개명) · `_inbox/logs/`: `YYYYMMDD_주제_log.md`
- INDEX: 각 도메인 `INDEX.md` + 전체 허브 `wiki/00_INDEX.md`

## 5. 페이지 규칙 (HARD)
frontmatter 필수(`title · maturity · domain · updated · source · links`). 한 파일 = 한 주제. 기존 페이지가 있으면 새 파일 대신 **갱신**(updated 갱신 + 내용 병합). 수정 시 도메인 INDEX 반영.

## 6. 성숙도 승격 조건
| 단계 | 조건 |
|---|---|
| idea | 한 번 떠오른 생각. compile 직후 기본값 |
| concept | 2회+ 재등장, 용어·정의 확정 |
| process | 실제 실행으로 검증된 절차 |
| framework | 2개+ 프로젝트에서 재사용됨 |
강등도 가능. 승격·강등은 ingest 브리핑 제안 → 사용자 승인으로만.

## 7. 주간 인제스트 브리핑 절차
① `_inbox` 신규 목록화 → ② 파일별 배치 제안(도메인·병합) → ③ 승격 후보 → ④ 중복·`links` 제안 → ⑤ 제안 표 → 승인 → 실행 → INDEX 갱신

## 8. 월간 린트 체크리스트
- [ ] frontmatter 누락·필드 불량 · [ ] 깨진 `[[링크]]` · [ ] 고아 파일 · [ ] INDEX↔실제 불일치 · [ ] `_inbox` 30일+ 방치

## 9. 타 프로젝트 연동
각 프로젝트 AGENTS.md에 배선 1줄: "○○ 도메인 요청 시 `../_Wiki/wiki/<도메인>/INDEX.md` 우선 참조". 위키 파일을 프로젝트에서 직접 수정하지 않는다(갱신은 위키에서). 충돌 시 최신 updated 우선.
